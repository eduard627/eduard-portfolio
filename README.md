# Eduard Meshchanin — Portfolio

Static one-page portfolio (EN / DE) hosted on Vercel.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `Eduard_Meshchanin_CV_EN.pdf`, `Eduard_Meshchanin_CV_DE.pdf` — downloadable CVs
- `eduard.jpg` — avatar, `og-image.jpg` — social preview, `favicon.svg`, `apple-touch-icon.png`
- `vercel.json` — clean URLs, PDF download headers, image caching

Language: auto-detected from the browser, switchable with EN / DE, direct link with `?lang=de`.
No build step: Vercel serves the folder as-is.
